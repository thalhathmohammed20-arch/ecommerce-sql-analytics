# SQL E-Commerce Analytics Project

## 📌 Project Summary
This project simulates an e-commerce platform with **customers, orders, and products**.  
I designed the schema, inserted sample data (120+ rows), and solved **30 business queries** across beginner, intermediate, and advanced levels.

## 🛠 Tools Used
- MySQL Workbench
- GitHub for version control

## 📂 Project Structure
- schema/create_tables.sql → database schema
- data/sample_data.sql → inserted values
- queries/beginner_query.sql → beginner queries (Q1–Q10)
- queries/intermediate_query.sql → intermediate queries (Q11–Q20)
- queries/advanced_query.sql → advanced queries (Q21–Q30)
- README.md → project summary

## 📊 Key Business Questions Answered
- Which customers placed the most orders?  
- Which product categories have the highest average price?  
- Who are repeat customers?  
- Monthly order summary view for dashboards
